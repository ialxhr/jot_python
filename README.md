# Быстрый Заметчик (Obsidian)

Лёгкое приложение для заметок на Python с интерфейсом Tkinter.

## Требования

- Windows
- Python 3.13 или совместимая версия
- Tkinter (обычно входит в стандартную установку Python для Windows)

## Запуск

1. Установите Python: https://www.python.org/downloads/
2. Скачайте репозиторий.
3. В папке с приложением выполните:

   ```powershell
   python app_fixed.py
   ```

## Зависимости

Если приложение использует только стандартную библиотеку Python, устанавливать дополнительные пакеты не нужно.

## Безопасность

Не публикуйте пароли, токены, личные заметки и локальные настройки.
