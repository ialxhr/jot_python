# Быстрый Заметчик (Obsidian)

Лёгкое настольное приложение для ведения заметок в Markdown в стиле Obsidian. Интерфейс построен на стандартном Tkinter; дополнительные Python-пакеты для запуска не требуются.

> Проект не является официальным продуктом Obsidian и не связан с командой Obsidian.

## Возможности

- Редактирование заметок в Markdown.
- Поддержка заголовков, списков, чекбоксов, ссылок, кода, выделения и других элементов Markdown.
- Работа с папками и файлами заметок.
- Быстрая вставка текста и ссылок.
- Поиск по заметкам и подсветка совпадений.
- Ежедневные заметки.
- Сворачивание разделов под заголовками, если поддерживается текущей версией приложения.

Возможности и внешний вид могут меняться по мере разработки.

## Требования

- Windows 10 или Windows 11.
- Python 3.10 или новее с установленным Tcl/Tk (обычно входит в установщик Python для Windows).
- Сторонние Python-библиотеки не требуются.

## Запуск

1. Установите Python с официального сайта: <https://www.python.org/downloads/windows/>. Во время установки убедитесь, что компонент **Tcl/Tk and IDLE** включён.
2. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив либо клонируйте репозиторий.
3. Откройте папку проекта в Проводнике.
4. В адресной строке папки введите `cmd` и нажмите Enter.
5. Выполните команду:

   ```powershell
   py app_fixed.py
   ```

Если команда `py` не найдена, попробуйте `python app_fixed.py`.

## Данные и резервные копии

Перед использованием важных заметок регулярно делайте резервные копии папки с заметками. Не загружайте в публичный репозиторий личные заметки, пароли, API-ключи или другие конфиденциальные данные. Код приложения и содержимое ваших заметок — разные вещи; храните заметки вне репозитория, если не хотите публиковать их.

## Сообщить об ошибке

При создании Issue укажите версию Windows и Python, шаги воспроизведения и текст ошибки из консоли. Не прикладывайте личные заметки и секреты.
